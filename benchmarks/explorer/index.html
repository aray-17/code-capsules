Code-Capsules evidence explorer

Every key claim in the paper reproduces offline from committed eval data. The Claims tab pairs each claim with the value reproduced from that data; the Eval runs tab is a labelled, searchable catalog of every run. Click any file to inspect it in the panel on the right. Build the data with bash benchmarks/explore.sh (or python3 benchmarks/verify_criteria.py && python3 benchmarks/build_evidence_index.py), served from the repo root over http (not file://).
